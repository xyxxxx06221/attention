<h1 align="center">主一 · ATTENTION</h1>

<p align="center"><strong>每天读完一份有尽头的材料，再留下自己的判断。</strong></p>

<p align="center">有限阅读 · 原文批注 · 个人档案 · AI 秘书</p>

主一是一款面向中文新闻、政策与公共议题的个人阅读工作台。最初的目的是服务于公务员考试中的时政部分，它把每天分散在不同网站上的材料收集起来，整理成一份有限的阅读清单，让你在同一个地方完成阅读、标记、思考、讨论与归档。

你可以关注全国，也可以加入自己关心的省份；可以只使用阅读与笔记功能，也可以接入自己的模型，让一位 AI 秘书协助检索、讨论和整理材料。

## 为什么做主一

在当今时代，获取信息已经很容易，困难的是怎么收缩自己的注意力，也就是 Attention is all you need(笑)。

无限下滑，很爽。

但一条接一条的推荐让阅读很难结束。收藏夹越来越长，却很少再被打开。摘要帮助我们快速知道结论，也可能让我们跳过原文中的依据、条件与细节。看过很多内容之后，我们仍然需要回答：哪些值得记住？哪些还没有想清楚？哪些会影响自己的工作与生活？

主一希望把这个过程放慢一点，也做完整一点：每天拿到一份可以读完的材料，认真看几篇原文，留下几段自己的话，然后结束今天的阅读，重点在于结束，你的注意力很宝贵，不要无休止的浪费，这也是人对抗AI的途径之一。

### 阅读应该有尽头

主一按期次组织材料，类似于杂志。当前全国卷最多 20 件，每个已配置省份最多 10 件。处理完一篇材料，不会因此自动补进另一篇来填满列表。

有明确的开始，也有明确的结束。读完之后，注意力可以回到工作、生活和行动中。

### 重要的信息，不必总是合口味

材料筛选依据来源权重、主题与公共重要性规则，不根据个人点击或批注偏好调整推荐。它希望帮助使用者持续接触值得了解的公共议题，而不是只重复已经熟悉、认同或愿意点击的内容。

这些规则并不等于对重要性的最终判断。主一保留来源和原始链接，让使用者能够核实、质疑，并逐步调整自己的阅读范围。

### 判断要由自己完成

主一把原文放在阅读流程的中心。你可以选中一句话，记录疑问、不同看法或好词好句，也可以在读完之后写下心得。

原文、个人修订稿和 AI 建议分别保存。对一篇材料的理解可以变化，但依据应该能够找回，自己的想法也应该有独立的位置。

### AI 承担秘书工作

采集、评分、去重和编选由爬虫与规则完成，更新材料不需要大模型。列表中的内容提要来自正文摘录。

AI 用于你主动发起的工作：查找已有档案、讨论一段原文、梳理问题、生成会议纪要，或提出专题整理建议。你可以追问它的依据、保留不同意见，并决定是否采用建议。

### 阅读积累应由使用者掌握

文章副本、标记、批注、心得和文稿保存在自己的电脑上，不需要注册主一账号。使用者可以管理来源、组织专题、导出档案和备份数据。

一次阅读可以结束，积累却能够继续生长。主一希望让今天的一句话，在下一次遇到相关问题时仍然找得到。

## 从一份材料开始

1. **准备阅读范围。** 默认提供全国与广东栏目。进入「设置 → 来源与采集」，可增添省份和来源。
2. **更新本期材料。** 在「今日阅文」点击「一键更新本期材料」，等待采集和规则编选完成。
3. **打开原文。** 选择一篇材料，阅读正文；需要更大的空间时，可拖动待阅列表与正文之间的分隔条。
4. **留下自己的话。** 标记、批注、摘录，或写一段阅后心得。需要讨论时，再请秘书参与。
5. **完成办理。** 根据需要略过、存档，或标记为已阅并归档。材料和思考随后可以从档案室、政研室继续找回。

没有模型接口，也可以完成采集、阅读、标记、笔记、个人修订与手动归档。

## 功能介绍

### 今日阅文：每天一份有限的清单

- 按日期期次和地区查看材料，支持标题、来源与主题检索。
- 一键更新本期材料，显示采集进度与缺项报告。
- 全国最多 20 件，每个已配置省份最多 10 件；按事件合并相关报道。
- 保留原始来源、发布日期及日期精度，方便回到原站核对。
- 可开启自动准备材料；电脑需要处于开机、唤醒和联网状态。

期次使用北京时间，窗口为前一日 07:00 至当日 07:00。自动准备默认关闭；开启后于 06:35 预收，07:00 后补齐。电脑休眠期间不会采集，恢复后尝试补收最近已结束的期次。

### 专注阅读：原文、标记和思考放在一起

三栏分别承担导航、待阅列表与原文阅读。一级导航保持稳定，待阅列表宽度可拖动调整，也支持方向键和阅读显示中的滑块。宽度偏好会保留。

- 调整字号或进入专注全屏。
- 在右上角打开个人稿编辑，原始正文继续保留。
- 对原文添加高亮、下划线和删除线，选择不同标记颜色。
- 记录批注、好词好句、存疑、不同看法与阅后心得。
- 在批注与讨论栏就当前材料向秘书提问，查看历史问答。

再次点按一处标记，可取消该处标记；同一处文字叠加了多个标记时一并取消，文字批注保留。

### 代办文件：把尚未完成的阅读留好

代办文件汇集尚未办理的材料，可以按已配置地区切换，并检索全文。它与当天期次相互配合，让暂时没读完的材料继续有地方可去。

三种办理操作各有用途：

| 操作 | 是否继续待阅 | 是否记为已阅 | 归档行为 |
| --- | --- | --- | --- |
| 略过 | 否 | 否 | 保留已有归档状态与笔记 |
| 存档 | 是，保持原阅读状态 | 不改变 | 保存到档案室 |
| 已阅归档 | 否 | 是 | 保存到档案室 |

### 档案室：让材料可以再次找到

档案室统一管理原文材料、研判文稿和会议纪要。

- 通过关键词、日期区间、地区、材料类型与专题组合查找。
- 新建专题与下级分类，修改名称、删除专题。
- 将材料归入专题，批量选择、归档或移入回收站。
- 阅读和编辑个人文稿，保留原始记录及修订版本。
- 导出档案，或请秘书提出整理建议，确认后应用。

删除专题时，文件保留在全部档案中。日期筛选中，原文使用发布日期，纪要与自动生成文稿使用其更新时间；引用多个地区材料的文稿可对应多个地区。

### 政研室：把自己的思考整理起来

政研室集中查看文章上的批注、摘录、疑问与心得，支持检索和类型筛选，并可返回关联原文。

你可以按文章管理这些记录，把不再需要的批注移入回收站。阅读后的积累既能独立查找，也能追溯到当时看到的材料。

### 办公室：与秘书围绕具体问题讨论

- 新建议事，按主题保留多段对话。
- 在自己的档案中检索材料，结合已有记录继续追问。
- 主动开启「联网查证」后，检索外部资料或附参考网页。
- 查看当日会议纪要，保存和修订自己的研判文稿。
- 管理议事与消息回收站，调整对话字号。

页面外层保持固定，对话记录在内部滚动，输入区保留在下方。原文副本、用户意见和秘书答复各自保留，便于比较和回看。

### 来源与省份：自己决定阅读范围

默认来源为：中国政府网、人民网、新华网时政、求是网、广东省人民政府、南方网。

- **全国来源固定保留。** 全国栏目不会因省份配置变化被删除。
- **省份可以增减。** 删除广东等省份时，同时移除对应来源配置，已有档案与批注继续保留。
- **新增省份必须提供来源。** 填写来源名称、HTTPS 栏目或 RSS / Atom 地址、所属地区与权重。
- **先测试，再保存。** 检查候选链接、正文与发布日期，测试通过后才能保存；修改参数后需要重新测试。
- **省份与来源一起生效。** 避免出现已经添加省份，却没有可用采集入口的情况。

测试会抽样读取文章。网站改版、访问限制或网络变化仍可能影响后续采集，因此可以随时重新测试并查看结果。

### 工作看板与接口用量

工作看板提供阅读和工作记录的阶段回顾，可查看不同时间范围的小结。接口用量入口用于查看模型调用统计；余额等信息是否可显示，取决于所配置服务的支持情况。

## 模型接口与费用

主一支持自行配置 Chat Completions 兼容接口。可使用本机模型服务，也可以填写自己的远程服务地址、模型名称和密钥。

| 功能 | 是否需要模型 |
| --- | --- |
| 采集、来源测试、规则评分、去重、更新本期材料 | 不需要 |
| 原文阅读、标记、批注、心得、检索与手动归档 | 不需要 |
| 编辑个人稿、管理专题、配置省份与来源 | 不需要 |
| 秘书问答、阅后梳理、请求 AI 更新纪要、AI 整理建议 | 需要 |

应用不附送模型额度，也不预装密钥。使用远程接口时，相关原文、问题、批注或检索资料可能发送到你选择的服务，费用按该服务规则计算。

「联网查证」默认不开启。未开启时，秘书仅检索本地数据库；开启后才进行外部查证。不同提供商的搜索能力和计费方式可能不同，详见 [接口与检索说明](docs/API.md)。

## 本地保存与版本独立

文章和个人记录保存在本机 SQLite 数据库中。主一不要求注册账号，不向项目作者上传个人档案，也没有自动同步到云端的功能。

v1.0.0 与已有版本使用独立标识。更新或试用时保留旧版本目录，不自动覆盖、迁移或清空原有档案。确需迁移时，应先备份，再按明确的迁移步骤操作。

桌面软件与个人数据分开保存：

| 版本 | 默认数据目录 |
| --- | --- |
| Windows 桌面版 | `%LOCALAPPDATA%\Zhuyi\v1` |
| macOS 桌面版 | `~/Library/Application Support/Zhuyi/v1` |
| 源码版 | 项目目录 `data/` |

可从桌面控制窗点击「打开数据文件夹」。替换或更新程序文件不会删除这些档案；旧源码版数据不会自动迁移。需要指定其他目录时，可使用环境变量 `ZHUYI_V1_DATA`。

备份时先停止服务，再复制完整数据目录。备份可能包含模型密钥和私人笔记；公开反馈、上传仓库或分享截图时，请不要包含这些内容。

## 当前边界

- 采集范围由配置来源决定。当前每个来源最多扫描 45 条候选，不代表覆盖网站全部栏目或全部事件。
- 时间只有日期时会保留精度说明，不把它伪装成准确的发布时分。
- 网页结构变化、访问限制、图片表格或视频内容可能导致正文提取不完整。请以原站为准。
- 事件合并主要依据标题，可能出现重复或误合并；规则筛选也可能遗漏值得关注的材料。
- AI 答复需要核对，资料不足时不应被当成已经核实的结论。
- 语音转写依赖浏览器支持与麦克风权限，可能使用浏览器厂商服务。
- 本地保存并不等于密钥加密保险库；请妥善保护电脑和备份。

## 开发者：从源码运行

普通使用者直接在上方选择对应系统下载。希望查看代码、修改功能或自行运行的使用者，可以使用源码版。

需要 Python 3.10+、系统 `curl` 与现代浏览器。当前业务后端使用 Python 标准库，前端使用原生 HTML、CSS 和 JavaScript，无需安装 pip 或 npm 依赖。

```bash
# Windows
python launch.py

# macOS / Linux
python3 launch.py
```

启动后访问 `http://127.0.0.1:8879/`。Windows 也可双击「启动主一.bat」，macOS 可使用「启动主一.command」。关闭浏览器不会停止后台；通过对应的停止脚本结束服务。

测试使用临时数据库与模拟模型，不调用用户的付费接口。当前本地 v1.0.0 已在 Windows 通过 98 项 Python 测试和 5 组前端检查，并完成源码发布包独立解压启动验证；Windows 与两种 Mac 架构还会分别验证实际打包程序的启动、静态资源、中文写入、重启持久化及退出。具体结果见该版本的构建记录。

主一提供本机 HTTP API，外部 Agent 可以在用户授权下读取来源、启动规则采集，或把核实后的原文导入档案。
