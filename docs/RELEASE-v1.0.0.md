# 主一 v1.0.0 · 本地版

双击目录中的「启动主一.bat」，打开 http://127.0.0.1:8879/ 。关闭浏览器不会停止后台；双击「停止主一.bat」停止。需要 Python 3.10+、系统 curl 和现代浏览器，无需安装第三方 Python 或前端依赖。

本版使用独立应用标识 `zhuyi-local-v1`、默认端口 8879 和独立 `data/`。原项目及云端版本保持不变。发布包不含档案、演示数据库、密钥或运行日志，首次运行创建空档案。

## 本次功能

- 保留三栏专注阅读。待阅与正文之间可拖动调宽，支持键盘左右键与阅读显示中的滑块，宽度自动保存。一级导航宽度固定。
- 个人稿编辑移至右上角；接口用量箭头修正；略过、存档使用蓝色按钮；政研室及办公室顶部按钮统一。
- 顶部显示提供的「主一」字标，保留原图标。不再显示“本地评审 · 独立档案”。
- 办公室外层固定，对话上下文内部滚动。手机窄屏提供独立列表、全文阅读与批注抽屉。
- 档案室专题卡片显示删除按钮，删除专题保留文件。支持日期区间、地区、类型、专题、全文检索组合筛选。
- 设置中新增、测试和删除来源；支持 HTML 栏目与 RSS / Atom。成功测试正文及日期后才能保存，修改参数后必须重测。
- 新增省份时同时提供来源；省份和通过测试的来源一起保存。删除省份同时删除对应采集配置，已有档案、批注保留。全国内置来源不可删除。
- 重加同一省份与来源后，重新采集可关联历史文章，保留批注。历史地区不会因此改写。
- 取消“取消所选标记”按钮。标记后提示再次点按删除；多个重叠标记一起取消，文字批注保留。
- 今日阅文恢复「一键更新本期材料」。爬虫、来源权重、主题规则及标题去重完成筛选，不使用模型评分、编选或摘要。内容提要为正文摘录。

## 办理规则

| 操作 | 待阅 | 已阅统计 | 档案 |
| --- | --- | --- | --- |
| 略过 | 移出 | 不计入 | 保留原有归档状态和笔记 |
| 存档 | 保持 | 不改变 | 收入档案 |
| 已阅归档 | 移出 | 计入 | 收入档案 |
