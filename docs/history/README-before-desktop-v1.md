# 主一 v1.0.0 · 本地版

**每天读完一份有尽头的新闻，再留下自己的判断。**

主一是运行在自己电脑上的中文新闻阅读 Web App。它将官方要闻收集、有限编选、原文阅读、标注、笔记、归档和 AI 讨论放进同一个工作台。

## 可以做什么

- **有限的日报**：全国最多20件、每个已配置省份最多10件，阅读结束后不会无限补位。
- **自己的阅读档案**：原文副本、五色高亮、下划线、摘录、批注、心得、专题和回收站。
- **本地模型 / 自选 API**：连接 Chat Completions 兼容接口，提供秘书问答、阅后梳理和会议纪要；无模型也能采集、阅读和整理。
- **Agent 协作**：让自己使用的 Agent 阅读官方来源，通过本机 HTTP API 把核实后的材料导入档案。
- **本地保存**：SQLite 保存文章与笔记，浏览器用于操作；不需要注册主一账号。

这是独立的本地 v1.0.0，原项目和已有云端版本保持各自独立。启动器运行完整 Python 后端，不是演示模式。

## 五分钟开始

准备 **Python 3.10 或更新版本**、系统 `curl` 和现代浏览器。Python 使用标准库，前端为原生 HTML/CSS/JavaScript，无需安装 pip 或 npm 依赖。

1. 将本地发布包解压到独立文件夹。不要覆盖旧版本目录。
2. 进入解压后的项目目录，运行：

```sh
# macOS / Linux
python3 launch.py

# Windows（已安装 Python 并加入 PATH）
python launch.py
```

3. 浏览器打开 `http://127.0.0.1:8879/`。也可在 macOS 双击「启动主一.command」，Windows 双击「启动主一.bat」。若下载文件被系统拦截，先检查来源与代码，再按系统提示操作；命令行启动也可。
4. 到「今日阅文」点 **一键更新本期材料**。首次启动是空档案，不附带作者的数据或预装模型密钥。

关闭浏览器不会停止后台。运行 `python3 stop_local.py`，或双击「停止主一」停止；Windows 使用 `python`。端口冲突时运行 `python3 launch.py --port 8766`，停止时也加 `--port 8766`。

自动采集**默认关闭**，可在设置中开启。开启后按北京时间06:35预收、07:00后补齐；电脑需开机、唤醒、联网。休眠期间不会运行，恢复后尝试补收最近已结束期次。前台调试用 `python3 app.py --no-scheduler`。

## 收集与秘书的分工

| 方式 | 需要什么 | 结果 |
| --- | --- | --- |
| 内置采集 + 规则 | 网络连接 | 从六个官方入口提取材料，按规则生成有限日报 |
| 自定义省份与来源 | HTTPS 新闻栏目或 RSS / Atom 地址 | 先测试正文与日期，再保存来源；仍仅按爬虫和权重筛选 |
| 外部 Agent + 本机 API | 能浏览网页并调用 HTTP 的 Agent | Agent 核实后导入档案；当前导入接口不自动建立日报期次 |

### 本地模型或自己的远程接口

在「主一设置 → AI 接口」填写 API 地址和模型名称，例如本机兼容服务的 `http://127.0.0.1:1234/v1`。端口及模型名称以你实际启动的服务为准。本机回环地址可不填密钥；需要鉴权的服务仍需填写。远程服务要求 HTTPS 和用户自己的密钥。

秘书会在地址后调用 `/chat/completions`。采集、评分、去重、编选和本期材料更新不调用大模型，内容提要为正文摘录。软件不附带模型、不代购额度，也不会默认替你选择收费服务。

秘书问答勾选“联网查证”后，DeepSeek 官方接口会复用现有密钥和模型执行原生网页搜索，再根据网页摘录或读取到的原网页生成带引用的答复，无需另外申请搜索服务密钥。搜索会额外消耗模型额度，接口返回的 token 纳入用量统计；当前模型须支持搜索工具。不勾选时只查本地数据库，资料不足如实说明。其他提供商保留原有网页检索方式，详见 [检索开关说明](docs/API.md#秘书检索开关)。

采集本身由本机程序完成，模型只处理提交给它的材料。模型问答可能发送相关原文、你的问题和批注到所填服务；选用远程服务前请确认其数据政策。

### 使用自己的 Agent

启动应用，将 [Agent 使用指南](docs/AGENT.md) 交给 Agent。可读取 `/api/sources`、调用 `/api/collect` 并查看 `/api/job`，也可用 `/api/import` 导入核实后的官方原文。

提供了不依赖第三方库的导入助手：

```sh
python3 tools/agent_import.py path/to/verified-article.json
```

JSON 格式参考 [导入模板](examples/article.template.json)。模板不是真实新闻，必须替换为实际核实材料后使用。接口字段与错误处理见 [本机 API](docs/API.md)。Agent 无需读取 `data/settings.json`，不要把自己的模型密钥写进导入文件。

## 默认来源与选稿边界

中国政府网、人民网、新华网时政、求是网、广东省政府、南方网。全国来源固定保留；广东可删除，删除时同步移除对应来源，历史档案保留。设置 → 来源与采集支持新增省份，必须同时提供且通过测试的来源。

- 时间窗口：前一日07:00至当日07:00，前闭后开，北京时间。
- 每来源最多45条首页候选，不能保证全栏目、全事件覆盖。报告保留失败、日期待核和候选上限情况。
- 时间只有日期时保留精度标记；无日期、网页结构变化、短讯、图片表格与视频可能影响提取。
- 当前事件合并主要依据标题，可能重复或误合并；规则权重也可能遗漏重要材料。重要信息应对照原站。
- 不根据个人点击或批注迎合选稿；AI 的建议与用户个人结论分别保存。
- 新闻版权属于原权利人。项目许可只授权代码及相关项目文件，不授权批量转载或向公众分发第三方全文。

## 数据与隐私

v1.0.0 使用独立端口 8879、应用标识 `zhuyi-local-v1`。数据默认保存在本版本目录下 `data/`；可通过环境变量 `ZHUYI_V1_DATA` 指定独立目录。密钥保存于本机 `settings.json`，不回传到设置页面，但不是加密保险库。停止服务后可备份整个数据目录，备份也可能含密钥与私人笔记，应自行妥善保管。

程序只监听本机 `127.0.0.1`，校验 Host 和浏览器来源，不带多用户认证。适用于自己的电脑；不要直接把端口映射到公网。代码不向项目作者发送遥测；采集会访问新闻网站，用户发起联网查证会访问搜索服务，浏览器语音识别可能调用浏览器厂商服务。

上传问题或分享仓库时，不要附上自己的 `data/`、备份、密钥、日志或私人截图。本公开版本不含作者的档案、账号配置、内部沟通记录和历史 Git 提交。

## 阅读与归档操作

- 略过：移出待阅，不记为已阅，保留已有文章及批注。
- 存档：收入档案，阅读状态不变，仍可继续待阅。
- 已阅归档：记为已阅并收入档案，同时移出待阅。
- 同一段文字有多个标记时，再点一下标记会取消该处全部标记，文字批注保留。
- 档案室按材料日期及地区联合筛选；原文用发布日期，纪要和自动文稿用更新时间。

手机版与桌面版使用同一页面，窄屏自动转为列表 → 阅读的布局。当前仅开放本机访问；手机尺寸预览不等于已开放手机联网访问。
