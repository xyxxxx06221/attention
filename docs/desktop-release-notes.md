# 主一 v1.0.0

每天读完一份有尽头的材料，再留下自己的判断。

最初服务于公务员考试中的时政阅读，现在把有限编选、原文阅读、个人思考与长期档案放进同一个工作台。采集、评分、去重与编选只使用爬虫和规则；AI 只在用户主动需要时承担秘书工作。

## 下载

- [Windows 10 / 11 · x64](https://github.com/xyxxxx06221/attention/releases/download/v1.0.0-desktop/Zhuyi-v1.0.0-Windows-x64.zip)：解压完整文件夹，双击 Zhuyi.exe。
- [Mac · Apple 芯片](https://github.com/xyxxxx06221/attention/releases/download/v1.0.0-desktop/Zhuyi-v1.0.0-macOS-arm64.zip)：解压，将 Zhuyi.app 拖入应用程序后打开。
- [Mac · Intel 芯片](https://github.com/xyxxxx06221/attention/releases/download/v1.0.0-desktop/Zhuyi-v1.0.0-macOS-x64.zip)：解压，将 Zhuyi.app 拖入应用程序后打开。

无需安装 Python 或 Node.js。启动后自动在默认浏览器打开完整工作台，保留控制窗即可使用。初次启动为空档案，不附带用户数据或模型密钥。

## 本版包含

- 三栏专注阅读，可调待阅列表宽度；中文主一字标、统一按钮与移动端布局。
- 一键更新本期材料；全国固定来源、自选省份、自定义来源与先测试后保存。
- 原文批注、摘录、个人修订稿与心得；日期、地区和专题档案管理。
- 政研室与办公室，档案检索、秘书讨论、文稿及会议纪要。
- 独立用户数据目录，保留旧版源码、历史与档案。
